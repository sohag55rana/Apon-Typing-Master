# Apon Typing Master

## Run locally

```sh
npm install
npm run dev
```

## Deploy to Vercel

The project is configured for Vercel with `npm run build` and `dist` as its
output directory. Connect the GitHub repository
[`sohag55rana/Apon-Typing-Master`](https://github.com/sohag55rana/Apon-Typing-Master)
to the Vercel project once in **Project Settings → Git**. After that, pushes to
the production branch deploy automatically, and pull requests get preview
deployments. No manual redeploy is needed for future code changes.
